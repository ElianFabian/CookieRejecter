## What's new

- Start a consent review from the floating **Reject optional choices** button. Pause, resume, or stop while it runs.
- On supported Google consent forms, CookieRejecter checks both the data and vendor switches and waits for you to confirm before saving. Optional completion alerts tell you when the review is ready.
- The activity log groups switch changes by app. The searchable **Apps to skip** list lets you choose where CookieRejecter runs.
- The interface is available in 12 languages. Google form matching covers English, Spanish, French, German, Italian, Portuguese, Japanese, Simplified Chinese, Russian, and Ukrainian.

## Install

Download **CookieRejecter-0.0.2.apk** from Assets and enable the service in Android Accessibility settings. If you already installed a debug build, switching to the signed release requires a one-time uninstall, which clears the debug build's settings.

The English Google form was tested in live Android apps. The other nine languages passed emulator tests, with live validation still pending.
