## What's new

- Fixed Google consent reviews that could stop after scrolling when a WebView reported outdated switch positions. CookieRejecter now asks the WebView to reveal the next rows and verifies each switch on screen.
- Faster reviews cover more vendor rows per scroll and verify two visible switch changes in one screenshot when possible.
- **Wait after scrolling** in Settings lets you choose the delay. When CookieRejecter cannot verify every switch, the warning opens this setting so you can adjust it and retry.
- The activity log and completion notification show how long the review took. Completion notifications stay available when the notification shade takes focus.

## Install

Download **CookieRejecter-0.0.3.apk** from Assets. It can update the previous signed GitHub release in place. If you installed a debug build, uninstalling it first lets Android install the signed APK. This clears the debug build’s settings.
